## Overview

This project is one of my earliest game development projects, created in 2016 while learning programming and interactive graphics.

The game recreates the classic Pong gameplay, featuring player-controlled paddles, ball physics, collision detection, score tracking, and keyboard input.

## Installation & Setup

### Prerequisites
- C++ compiler (C++11 or later)
- OpenGL development libraries
- GLUT/FreeGLUT

### Compilation
```bash
g++ -o pong main.cpp -lGL -lGLU -lglut
./pong
```

## Features

- Two-player local multiplayer
- Keyboard controls
- Real-time rendering using OpenGL
- Ball movement and collision detection
- Score system
- Start and game-over states

## Technologies

- C++
- OpenGL
- GLUT

## Controls

Left Player:
- W: Up
- S: Down

Right Player:
- Arrow Up: Up
- Arrow Down: Down

## Historical Context

Developed in 2016 as my first complete game project.

Although simple, this project introduced concepts that would later become central to my work in game development, computer graphics, simulation systems, and real-time interactive applications.
